# Board media

Real photos and short clips shown on Profe's board with the `media` board scene
(`"board": { "scene": "media", "image": "assets/media/027/photo.jpg", "credit": "Foto: Autor · CC BY-SA 4.0" }`).

- One folder per episode number: `assets/media/<NNN>/` (e.g. `027/`). Episode JSON paths are relative to
  `hf-template/`.
- Photos (jpg/png/webp): committed. Keep them reasonably small (about 1600 px on the long side is plenty for the
  1280x886 board).
- Clips (mp4/webm/mov): **not committed** (gitignored, like rendered videos). Keep the source URL in the episode's
  `sources` so the clip can be downloaded again.
- `_frames/`: generated by `scripts/build-audio.mjs` (30 fps JPEG sequences of each clip cut). Gitignored, safe
  to delete; the next build re-extracts.
- Only media we may publish: public domain, Creative Commons (credit shown on the board), or our own.
