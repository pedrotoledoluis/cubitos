# Episodes 027–032 — research + script drafts

Drafted 2026-10-31 (U2 of `odd/tasks/episodes-027-032.md`). Format v2: 35–55 s (aim ≤ 52 s), ~11–12 lines,
1-second hook, Profe ≤ ~14 words, Tito 1–7 words, last line = Tito loop punchline + Profe facepalm.

## Conventions used in this file

- **Projector cue** (template feature U1, done in f0f4b21; see PRODUCTION.md): every "photo `X`" cue below means
  `board: { "scene": "media", "image": "assets/media/<NNN>/X", "credit": "Foto: <author> · <license>", "title": "..." }`
  (or `"clip"` for a ≤5 s cut). Download the Commons file into `hf-template/assets/media/<NNN>/` first.
  Where no licensed media exists, the cue uses an existing board scene (`showcase`, `bars`, `emojiVs`, `equation`…)
  or a **stylized title card** (`titleCard`, new, see below).
- **Copyright**: no film stills, posters, logos or character likenesses. Films = title card with a generic icon
  (kitchen knife + pumpkin, music box, bed + moon, red-haired doll silhouette, cross) + the score.
- **Duration estimate**: Profe/Nova Kokoro ≈ 2.6 words/s (18 words ≈ 7 s), Tito SAPI ≈ 2.8 words/s, +0.25 s gap per
  line, +0.2 s after board lines, +0.3 s before a location change, +~0.6 s on location wipes. Always confirm with
  `build-audio` (`timeline:`); each script lists a line to cut if it runs long.
- **Verification marks**: ✅ checked against the cited page today · ⚠️ widely reported but not re-verified today /
  needs a check before render.
- New assets proposed (all optional; a fallback that already exists is given each time):
  - Costumes: `acomodador` (cinema usher: red cap + red vest + flashlight), `puritano` (1692 Puritan: tall black
    hat with buckle, white flat collar), `nikolaus` (St Nicholas bishop: red-and-gold mitre, red cope, crozier).
  - Locations: `cine_terror` (old cinema: red seats, projector beam, screen = board), `suburbio_halloween` (US
    suburban street at night: lit houses, inflatable skeleton, jack-o'-lanterns, fog), `alpine_village` (snowy
    Austrian village at night: wooden chalets, church spire, lantern-lit street, falling snow).
  - Board scene: `titleCard` (`num`, `icon`, `title`, `value`, `sub`): a ranking card with a generic icon. Could be
    built from `newsCard` (ep 025) by swapping the icon set.
